### Libraries

#### Rust

- `ariadne`: beautiful diagnostic/error reporting
- `axum`, `axum-extra`: ergonomic web framework built on tower
- `base64`: base64 encoding/decoding
- `bitflags`: type-safe bitflag enums
- `chrono`: date and time handling
- `chumsky`: parser combinator library
- `clap`: command-line argument parsing
- `cranelift`: fast code generator (alternative backend for rustc)
- `dialoguer` + { `indicatif`, `console` }: CLI prompts, progress bars, terminal styling
- `diffy-imara`: fast diffing library
- `dotenvy`: load .env files into environment
- `facet`: reflection and serialization framework
- `genai`: multi-provider LLM client
- `hex`: hex encoding/decoding
- `inquire`: interactive CLI prompts
- `jsonwebtoken`: JWT creation and validation
- `oauth2`: OAuth2 client implementation
- `polars`: fast DataFrame library
- `proc-macro2`: proc macro token stream utilities
- `quote`: quasi-quoting for proc macros
- `ratatui`: terminal UI framework
- `reqwest`: async HTTP client
- `serde`, `serde_json`: serialization/deserialization framework
- `sha2`: SHA-2 hash functions
- `sqlx`, `pgvector`: async SQL toolkit + vector similarity for postgres
- `syn`: Rust source code parser (for proc macros)
- `thiserror`, `anyhow`: typed errors / ad-hoc error handling
- `tokio`: async runtime
- `tower-http`, `tower-governor`: HTTP middleware + rate limiting
- `tracing`, `tracing-subscriber`: structured logging and diagnostics
- `utoipa`, `utoipa-swagger-ui`: OpenAPI doc generation + Swagger UI
- `uuid`: UUID generation and parsing
- `wasm-bindgen`, `wasm-pack`: Rust <-> JS interop for WebAssembly
- `wasmtime`: standalone WebAssembly runtime
